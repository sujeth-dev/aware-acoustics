## Web research trail
- **"Pristine Design Studio LLP"** is a real, verifiable interior design / architecture firm based in
  Bengaluru (Sanjay Nagar / Geddalahalli area). Confirmed via IndiaMART, JustDial, Tracxn/IndiaFilings
  company-registry listings, and the firm's own site, **pdsconsulting.in**. This is almost certainly the
  client named in the deck line above — i.e. "Pristine Design Studio" reads as the *design/build firm*
  that commissioned or executed the studio fit-out for which Aware Acoustics did the acoustic
  consulting, not the trading name of the recording studio itself.
- pdsconsulting.in's own portfolio page (`portfolio.php`) was fetched and lists only: Concorde Office,
  S4 Salon & Spa, Intime Tec, BIAL (Bangalore International Airport), TNC, HMIN, Presidency University,
  Goa CEE Office. **No recording studio / music studio project appears in their public portfolio.**
- Their Facebook page (facebook.com/PristineDesignStudio) carries no visible recording-studio content.
- Generic searches for "Pristine Studio(s)" recording studio (India, Mumbai, Bengaluru, Chennai) surface
  only unrelated facilities (e.g. a Buenos Aires production suite, various Indian studios with similar
  but non-matching names) — none tie back to Pristine Design Studio LLP or to Aware Acoustics.
- Aware Acoustics itself is confirmed real (Bengaluru-based; principal consultant Padmanabha B, IIT
  Kharagpur-certified, LinkedIn-verified), but their own site (awareacoustics.in) is "under construction"
  and has no case-study content to cross-reference.
